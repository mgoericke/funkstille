# Funkstille

Kleine First-Person-Demo in einem überwucherten Berliner U-Bahnhof, gebaut mit Godot 4.7.
Du bist allein im Dunkeln, ein blinder Lauscher hört jeden Schritt. Das Funkgerät zeigt dir den Weg nach draußen – aber es rauscht, und Rauschen ist Lärm.

## Starten

Godot 4.7 öffnen, Ordner wählen, F5. Tests: `bash tests/run.sh`.

## Steuerung

| Aktion | Tastatur/Maus | Controller |
|---|---|---|
| Gehen | W A S D | Linker Stick |
| Blicken | Maus | Rechter Stick |
| Ducken | C / Strg | B |
| Sprinten | Shift | Linker Stick drücken |
| Taschenlampe | F | Y |
| Funkgerät | R | X |
| Benutzen | E | A |
| Werfen | Linke Maustaste | Rechter Trigger |
| Pause | Esc | Start |
